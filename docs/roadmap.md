# Roadmap

Implemented work focuses on a reliable local runtime: shared channel contracts, observable model
and tool execution, Tavily research, safe webpage reading, memory, and opt-in chat integrations.

Potential future work includes persistent distributed deduplication, richer attachment ingestion,
trace export, pluggable telemetry backends, stronger multi-tenant authentication, and repeatable
live integration test harnesses. Google Workspace and Microsoft 365 integrations are not planned
in the current scope.
